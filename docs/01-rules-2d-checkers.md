# 二维跳棋规则参考

本文档整理二维“跳棋”的规则，作为三维跳棋的设计参考。  
实现时请把这里的规则抽象成参数开关，而不是写死在代码里。

---

## 1. 中国跳棋 / Sternhalma / Halma

### 1.1 棋盘

- 经典棋盘为六角星形（Sternhalma）
- 通常支持 2 / 3 / 4 / 6 人
- 每名玩家拥有一个三角形基地
- 常见棋子数为每方 10 或 15 枚
- 目标：**第一个把所有棋子从自己基地移动到对面目标区的玩家获胜**

### 1.2 走法

每回合玩家可以：

1. **走一步**  
   将一个棋子移动到相邻的空格。

2. **跳一步**  
   如果某方向上相邻一格有一颗棋子（任意颜色），并且该棋子后面的空格为空，则可以跳过该棋子，落到后面的空格。

3. **连跳**  
   跳完之后，如果新位置仍然可以继续跳，则可以继续跳。  
   可以一直跳到不能再跳为止。  
   **中国跳棋规则允许玩家自由选择在任意一个合法的中间落点停下。**

### 1.3 跳跃对象

- 可以跳过己方棋子
- 也可以跳过对方棋子
- 被跳过的棋子不会消失，只是作为“垫脚石”

### 1.4 目标区规则

常见变体：

- 标准：只要先填满目标区即可获胜
- 部分实现：棋子不能停留在对方目标区，只能“借道”经过
- 部分实现：不能停留在非自己基地、非中立区的某些位置
- 这些都应作为开关

### 1.5 连跳的数学表示

二维中，一个连跳路径可以表示为：

```text
start -> jump_mid_1 -> land_1 -> jump_mid_2 -> land_2 -> ...
```

## 2. 国际跳棋 / Draughts

### 2.1 与跳棋的区别

国际跳棋（西洋跳棋）是有吃子机制的对抗棋：

- 跳过对方棋子时，**被跳过的棋子被移除**
- 如果存在可吃子的跳法，通常**必须吃子**
- 连跳时，**通常不能停在中间，必须跳到尽头**
- 棋子到达底线后可以升王，王有更强的移动能力

### 2.2 关键开关

| 开关 | 中国跳棋 | 国际跳棋 |
|---|---|---|
| 跳过己方 | 允许 | 不允许（通常） |
| 被跳子是否移除 | 否 | 是 |
| 吃子是否强制 | 否 | 是 |
| 连跳落点 | 可自由选择 | 必须跳到底 |
| 升王 | 无 | 有 |

## 3. 扩展规则：空一格跳一格

这是一种可选的“远跳”变体：

- 在某个方向上：
  - 第 1 格为空
  - 第 2 格有棋子
  - 第 3 格为空
  - 第 4 格也为空
- 则可以“隔着一格”跳过第 2 格的棋子，直接落到第 4 格

它本质上把“一步跳”扩展成“两格跳”。

可以继续扩展：

```text
空 棋 空 空   -> 跳过棋到第4格
空 空 棋 空 空 -> 跳过棋到更远位置
```

这类规则在传统棋类中并不统一，所以必须做成配置开关。

## 4. 抽象后的核心规则模型

无论中国跳棋还是国际跳棋，都可以抽象成：

### 4.1 移动向量

在一个正交网格中，移动方向用向量表示：

```text
(1, 0)   右
(-1, 0)  左
(0, 1)   下
(0, -1)  上
(1, 1)   右下
...
```

### 4.2 基础跳规则

对于方向向量 `v`：

```text
p       : 当前棋子位置
p + v   : 被跳的棋子位置（必须有人）
p + 2v  : 落点（必须为空）
```

满足上述条件即可执行一次跳跃。

### 4.3 连跳

在一次移动中，可以连续执行多个跳跃。

```text
p -> p+2v1 -> p+2v1+2v2 -> ...
```

每次跳跃的方向可以相同，也可以不同。

### 4.4 落点控制

- `HOP_MODE = FREE_STOP`：玩家可以在任意中间落点停止
- `HOP_MODE = FORCE_ALL`：玩家必须跳到无法继续跳为止
