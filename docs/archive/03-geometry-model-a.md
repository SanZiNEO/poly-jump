# A 模型几何：XYZ 正交网格

## 1. 概述

A 模型是标准的笛卡尔三维网格。

- 棋盘形状：正方体或长方体
- 坐标原点：棋盘一个角
- 所有格点都是合法点
- 适用于 6 / 12 / 8 / 14 / 18 / 20 / 26 向移动

---

## 2. 坐标系统

设棋盘为：

```text
a = x 方向长度
b = y 方向长度
c = z 方向长度
```

坐标范围：

```text
x ∈ [0, a-1]
y ∈ [0, b-1]
z ∈ [0, c-1]
```

原点：

```text
(0, 0, 0) 位于一个角
```

三维坐标扁平化：

```text
index = x + y * a + z * a * b
```

## 3. 生成合法点

```python
def generate_points(a, b, c):
    points = []
    for z in range(c):
        for y in range(b):
            for x in range(a):
                points.append((x, y, z))
    return points
```

## 5. 邻居生成

> **所有移动都是沿向量的直线移动。**  
> 6 / 12 / 8 向和自定义向量完全一致：移动只看起点和终点（跳跃还要看一个被跳位置），中间不逐格检查。

给定一个点 `(x, y, z)` 和方向向量 `(dx, dy, dz)`：

```python
def neighbor(p, v):
    return (p[0] + v[0], p[1] + v[1], p[2] + v[2])
```

判断是否在棋盘内：

```python
def is_inside(p, a, b, c):
    x, y, z = p
    return 0 <= x < a and 0 <= y < b and 0 <= z < c
```

跳跃：

```python
def jump_destination(p, v, a, b, c):
    mid = neighbor(p, v)
    dest = neighbor(p, (2 * v[0], 2 * v[1], 2 * v[2]))
    return mid, dest
```

## 6. 初始基地：角上的金字塔

### 6.1 金字塔形状

在角 `(0,0,0)` 方向生成一个金字塔。

第 `k` 层是一个三角形：

```text
1
3
6
10
15
21
28
```

对应坐标：

```text
层 0：{(0,0,0)}
层 1：{(0,1,0),(1,0,0),(1,1,0)} 等
```

每层在 3D 中再沿 z 堆叠。

### 6.2 每方棋子数

```text
层数 = 4 时：1+3+6+10 = 20
```

### 6.3 实现建议

用程序生成金字塔坐标：

```python
def generate_pyramid(corner, layers):
    # 以 corner 为原点，生成直角三角形金字塔坐标
    cells = []
    for layer in range(layers):
        for dx in range(layer + 1):
            for dy in range(layer + 1 - dx):
                cells.append((corner[0] + dx,
                              corner[1] + dy,
                              corner[2] + layer))
    return cells
```

> 注意：该公式只是示例，实现时需要用具体坐标测试，确保基地形状正确。

## 7. 目标区

- 2 人局：玩家 A 基地在角 `(0,0,0)`，目标区是角 `(a-1,b-1,c-1)` 的同形金字塔
- 多人局：由配置显式指定每个玩家的目标区
- 3 人局：目标角可以是空的，即目标区不属于任何玩家起点

## 8. 渲染：点与线

### 8.1 点

前端渲染所有合法格点：

```text
每个点对应三维坐标 (x, y, z)
```

### 8.2 路线

根据启用的方向集，为每对可一步直达的点绘制线段。

可以按方向类型着色：

| 方向类型 | 建议颜色 |
|---|---|
| 轴 6 向 | 淡蓝色 |
| 两轴 12 向 | 淡绿色 |
| 三轴 8 向 | 淡紫色 |
| 自定义 | 淡橙色 |

线使用半透明材质。

## 9. A 模型的对称性

- 正方体具有 48 种旋转反射对称
- 长方体只保留较小对称群
- 训练时做数据增强需要按实际几何计算对称操作
