# 前端界面与交互设计

## 1. 页面结构

前端分两个页面：

```text
主菜单页面
  -> 选择配置
  -> 生成配置
  -> 进入游戏页面

游戏页面
  -> Three.js 3D 场景
  -> 点阵 / 路线 / 棋子
  -> 交互操作
```

---

## 2. 主菜单页面

### 2.1 配置项

主菜单需要提供：

- 几何模型：A / B
- 棋盘大小：
  - A：x / y / z
  - B：奇数边长
- 玩家数：2 / 3 / 4 / 6 / 8
- 方向集：
  - 6
  - 8
  - 12
  - 14
  - 18
  - 20
  - 26
- 自定义向量（可选）
- 移动规则：
  - 允许普通移动
  - 允许跳跃
  - 允许连跳
  - 连跳模式：自由停 / 必须跳到底
  - 空一格跳
- 吃子模式：
  - 无
  - 西洋跳棋式
  - 混合式
- 初始布局：
  - 金字塔层数
  - 基地形状

### 2.2 配置生成

主菜单点击“开始游戏”后：

```text
收集表单值
  -> 生成 PolyJumpConfig JSON
  -> POST /api/game/new
  -> 跳转到游戏页面
```

---

## 3. 游戏页面

### 3.1 Three.js 场景

用 `three.js` 渲染：

- `Scene`
- `PerspectiveCamera`
- `OrbitControls` 或自定义鼠标控制
- `WebGLRenderer`

### 3.2 点阵渲染

第一阶段：

- 只渲染棋盘点
- 不渲染完整网格
- 每个点用小圆球或小方块表示
- 棋子用不同颜色或大小区分

### 3.3 路线渲染

根据配置中的方向集，连接可一步移动的点：

```text
点 A ---------- 点 B
```

每个方向类型可以用不同颜色：

| 方向 | 颜色 |
|---|---|
| 轴 6 向 | 淡蓝 |
| 两轴 12 向 | 淡绿 |
| 三轴 8 向 | 淡紫 |
| 自定义 | 淡橙 |

路线使用半透明材质，降低视觉干扰。

---

### 3.4 相机交互

- 鼠标左键拖动空白区域：任意方向旋转
- 鼠标右键 / 中键拖动：平移
- 滚轮：缩放
- 可以按键盘快捷键重置视角

不需要限制在固定角度，必须支持任意方向旋转以观察三维结构。

---

### 3.5 点击选子

- 鼠标点击棋盘上的点
- 如果该点是当前玩家棋子，则选中
- 选中后突出显示该棋子

---

### 3.6 合法路径高亮

选中棋子后，从后端获取该棋子的全部合法路径：

```json
{
  "paths": [
    [[0,0,0], [1,0,0]],
    [[0,0,0], [2,0,0]],
    [[0,0,0], [2,0,0], [4,2,0]]
  ]
}
```

前端需要：

- 高亮所有可以到达的终点
- 高亮路径线
- 对连跳路径给出轨迹动画或虚线
- 点击任意终点即可提交完整路径

---

### 3.7 落子

- 点击合法终点后，显示完整路径
- 前端将路径发送给后端：

```json
POST /api/game/{id}/move
{
  "path": [[0,0,0], [2,0,0], [4,2,0]]
}
```

- 后端校验并更新棋盘
- 前端刷新棋子状态

---

### 3.8 棋谱记录

游戏页面需要：

- 右侧/底部显示历史棋谱
- 可以撤销 / 回放
- 可以保存为自定义格式

## 5. 渲染数据接口

后端返回：

```json
{
  "points": [[x, y, z], ...],
  "routes": [{
    "from": [x, y, z],
    "to": [x, y, z],
    "type": "axis6" | "face12" | "body8" | "custom"
  }],
  "pieces": {
    "[x,y,z]": 1
  },
  "current_player": 1,
  "bases": {
    "1": [[x,y,z], ...]
  },
  "targets": {
    "1": [[x,y,z], ...]
  }
}
```

## 6. AI 对局界面

- 可以设置“人类 vs AI”或“AI 自对弈”
- 人类模式：显示合法路径
- AI 模式：后端返回 AI 选择的路径，前端动画展示
- AI 可设置强度 / 思考时间

---

## 7. 视觉风格建议

- 深色背景
- 点阵用柔和荧光色
- 路线低透明度
- 棋子用高亮材质
- 当前玩家颜色区分明显
- 选中棋子有发光效果
