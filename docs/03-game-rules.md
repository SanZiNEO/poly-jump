# 游戏规则

## 1. 通用移动规则

- 所有移动沿移动向量直线移动
- 普通移动：`p -> p + v`
- 跳跃：`p -> p + 2v`
- 两格跳：`p + v` 空、`p + 2v` 有子、`p + 3v` 空、`p + 4v` 空
- 直线路径上的其他中间位置不作为阻挡点

### 移动类型

| 类型 | 说明 |
|---|---|
| 普通移动 | 移动到相邻空位 |
| 单跳 | 跳过一个棋子 |
| 连跳 | 连续多次跳跃 |
| 两格跳 | 空一格跳 |
| 自由停 | 连跳可停在任意落点 |
| 强制跳到底 | 必须跳到不能继续为止 |

## 2. 游戏模式

| 模式 | 目标 | 吃子 |
|---|---|---|
| 中国跳棋 | 把所有棋子搬运并填满对方目标区 | 无 |
| 西洋跳棋 | 吃光所有对手棋子 | 被跳棋子移除 |
| 混合模式 | 仍以搬运填目标区为主 | 被跳棋子送回本方基地 |

### 基地内保护

- 默认对方基地内跳过棋子不算吃子、不移除
- 可通过 `capture_in_base` 开启“基地内也允许吃子”

### 混合模式细节

- 被跳棋子优先放回本方基地空格
- 基地满则放基地边缘最近空格

## 3. 胜利条件

| 模式 | 胜利条件 |
|---|---|
| 中国跳棋 | 先填满目标区 |
| 西洋跳棋 | 最后仍有棋子的玩家获胜 |
| 混合模式 | 先填满目标区 |

## 4. 无棋可走

当前玩家无合法走法时自动跳过，轮询到下一个有合法走法的玩家。

## 5. 积分制

配置：

```text
ScoringConfig
```

| 规则 | 默认分 |
|---|---|
| 连跳每次 | +1（临时分，可设计分上限） |
| 吃子每次 | +2 |
| 进入目标区 | +1（仅从目标区外部进入时计算） |
| 胜利奖励 | +10 |
| 西洋棋存活棋子 | 每子 +1 |

目标区积分规则：

```text
只有从目标区外进入目标区才算分
目标区内移动、穿过目标区后离开，都不再计分
```

连跳计分上限：

```text
chain_max_scoring
0 = 不限制
正整数 = 最多只按该次数计分
连跳本身长度不受限
```

连跳临时分：

- 胜者保留临时分
- 败者临时分扣除
- 普通跳不加分
