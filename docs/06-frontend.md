# 前端

## 技术

- HTML + Three.js
- CDN 引入
- 无复杂构建

## 页面

### 主菜单

- 黑白灰 UI
- 四栏横向排列：棋盘 / 移动方向 / 规则 / 积分
- 中文标题：三维跳棋
- 英文标题：3D Jump Chess
- 几何模型选择
- 玩家数选择
- AI 玩家设置（与玩家数联动）
- 方向规则自动扫描
- 层数/半径配置
- 积分配置栏
- 中英文切换

### 游戏页面

- 3D 棋盘渲染
- 点阵 / 路线 / 棋子
- 基地按玩家颜色渲染
- 选子
- 合法路径高亮
- 点击落子
- 玩家列表
- 积分表
- AI 玩家切换 / 自动对弈
- 对局记录 / 回放

## 语言配置

文件：

```text
frontend/i18n.js
```

- 中文 / English 切换
- 保存到 localStorage
- 主菜单右上角选择语言

## 回放

- 显示每一步历史
- 点击历史跳转
- 上一步 / 下一步 / 开局 / 最后一手
- 自动播放
- 回放模式禁止误操作

## 渲染优化

- 空白点合并为单个 THREE.Points
- 路线按方向组用 LineSegments
- 限制 pixelRatio
- 高亮路径临时显示
